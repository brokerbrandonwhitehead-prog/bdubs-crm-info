Privacy and Google data use

Updated October 16, 2026. This notice describes the private CRM operated by Brandon Whitehead, using the brokerage Google account. It is not a public hosted CRM service.

Information accessed

The application checks the connected Google account identity. It reads supported inquiry metadata, snippets, headers, existing Gmail labels, property-related correspondence, and selected property-document attachment bytes. It captures names, email addresses, property context, source identifiers, and document evidence. It reads Google Drive folder and file metadata to verify mapped destinations and exact existing copies.

Purpose and permissions

Google data is used to maintain the owner’s brokerage contact and property records, preserve source evidence, capture documents, prevent duplicate copies, and support owner-directed review. Gmail access is read-only. Google’s Drive permission is broader than the operations implemented by this application; the application limits its writes to creating document files inside mapped property folders. It checks existing copies and does not move, overwrite, delete, or change sharing of existing files. It does not send email or assign buyer qualification automatically.

Storage, sharing, and retention

CRM records, document copies, and backups are stored locally under the owner’s Windows account. Approved documents may also be stored in the owner’s Google Drive folders. OAuth credentials are stored separately from ordinary record exports. Access depends on the security of the owner’s computer and Google account. This website contains no CRM records.

The application does not sell Google data, use it for advertising, or send it to AI services for model training. It does not provide other users with CRM access. Data remains until the owner chooses to remove it. Revoking Google authorization stops future access but does not automatically remove existing local records, backups, or previously saved Drive files.

Google API commitments

Google API data is used only to operate this private CRM, in accordance with the Google API Services User Data Policy and its Limited Use requirements.

Control and contact

The owner can revoke access in Google Account connections and stop local synchronization. For questions, corrections, or removal requests, contact brokerbrandonwhitehead@gmail.com.
